## 🚀 **Ab kya kare:**

### **Step 1: Firebase Console** (3 min)
```
https://console.firebase.google.com/
```
1. Google account से login
2. "Add project" → naam दें: "MyNotes"
3. Create करें

### **Step 2: Web App Register** (1 min)
1. Web icon (`</>`) click करें
2. App name: "Notes Manager"
3. "Register app"
4. **Config code COPY करें!**

### **Step 3: Config Update** (30 sec)
1. **`firebase-config.js`** file खोलें
2. Lines 4-11 में अपना config **paste** करें
3. **Save** करें (Ctrl+S)

### **Step 4: Services Enable** (2 min)

#### Authentication:
- Left menu → "Authentication" → "Get started"
- Google enable करें
- Email/Password enable करें

#### Firestore:
- Left menu → "Firestore Database" → "Create"
- "Test mode" → Location: asia-south1 → Enable

#### Storage:
- Left menu → "Storage" → "Get started"
- "Test mode" → Done
